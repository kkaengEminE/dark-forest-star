# Dark Forest Star

어둠의 숲에서 별 조각을 모아 빛이 되는 탐험/크래프팅 게임.

## Tech Stack

| 구분 | 기술 |
|------|------|
| 언어 | TypeScript (ES2020) |
| 게임 엔진 | Phaser 3.80 |
| 3D 렌더링 | Three.js 0.183 |
| 빌드 도구 | Vite 6.0 |
| 배포 | gh-pages |

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 미리보기
```

## 게임 설명

플레이어는 어둠의 숲 한가운데에서 촛불 하나를 들고 시작합니다. 숲에 흩어진 **별 조각**을 채굴하고 수집하여 상위 등급으로 합성한 뒤, 맵 꼭짓점의 나무에 **마법의 별**을 배치해야 합니다. 모든 꼭짓점이 채워지면 맵 중앙에 거대한 별이 나타나고, 그곳에 도달하면 승리합니다.

숲에는 **망치동물**이 배회하며 플레이어의 빛을 감지해 공격합니다. **NPC**와 협력하여 채굴 보너스를 얻을 수도 있고, 공격하여 조각을 뺏을 수도 있지만 — 폭력적인 행동이 누적되면 플레이어 자신이 망치동물로 변해 게임이 끝납니다.

## 조작키

### 게임 플레이

| 키 | 동작 |
|----|------|
| `W` `A` `S` `D` / 방향키 | 이동 |
| `SPACE` | 공격 (근접 범위 40px) |
| `Z` | 채굴 시작/중지 · 꼭짓점에 별 배치 · 꽃집 열기 |
| `Q` | 은신 토글 (적에게 보이지 않음) |
| `E` | 인벤토리 열기/닫기 |

### 인벤토리 (E로 열었을 때)

| 키 | 동작 |
|----|------|
| `1` | 합성: RAW 조각 10개 → MERGED 1개 |
| `2` | 제작: RAW 조각 5개 → 기본 별 지팡이 1개 |
| `3` | 조각 소비 → 경험치 획득 |
| `4` | 조각 소비 → HP 회복 |

### 꽃집 (Z키로 열었을 때)

| 키 | 동작 |
|----|------|
| `1` | 꽃 구매 (✦합성 x1) |
| `2` | 금빛 꽃 구매 (✧초합성 x1) |
| `3` | 특별한 꽃 구매 (✧초합성 x 난이도 꼭짓점 수, 1회 한정) |
| `Z` | 꽃집 닫기 |

### 메뉴

| 키 | 동작 |
|----|------|
| 마우스 클릭 | 메뉴 선택 (시작하기 / 설정 / 암흑의 숲이란) |
| `ENTER` | 재시작 / 다음 난이도 |
| `ESC` | 타이틀로 돌아가기 |

## 목표 조건

### 승리 조건

1. 난이도에 따른 **별 다각형 맵**의 모든 꼭짓점에 별 조각을 배치
   - STAR_5 / STAR_6: 각 꼭짓점에 **MERGED (✦)** 필요
   - STAR_8 / STAR_12: 각 꼭짓점에 **SUPER_MERGED (✧)** 필요
2. 모든 꼭짓점 완성 시 맵 중앙(1600, 1600)에 **중앙 별** 출현
3. 중앙 별에 접근(50px 이내)하면 **승리 엔딩**
   - 일반 엔딩: *"별이 되었습니다 — 어둠의 숲에 빛이 되어 남았습니다"*
   - **진엔딩**: 특별한 꽃을 구매한 상태에서 클리어 시 *"꽃이 피었습니다 — 어둠 속에서, 빛이 아닌 생명을 피워냈습니다"*

### 패배 조건

| 조건 | 설명 |
|------|------|
| **빛 소멸** | HP가 0이 되면 불이 꺼지고 게임 오버 |
| **망치 변이** | 망치점수 ≥ 50 AND 망치점수 > 빛점수 × 2 → 망치동물로 변이 |

## 핵심 시스템

### 빛 시스템

플레이어는 레벨업으로 광원을 업그레이드합니다.

| 레벨 | 광원 | 밝기 | 범위 | 최대 연료 | 소모율(/초) |
|------|------|------|------|-----------|-------------|
| 1 | 촛불 | 0.3 | 80px | 100 | 1.0 |
| 2+ | 전구 | 0.5 | 130px | 150 | 0.8 |
| 4+ | LED | 0.7 | 180px | 200 | 0.5 |
| 6+ | 스포트라이트 | 0.85 | 240px | 250 | 0.4 |
| 8+ | 투광등 | 1.0 | 320px | 300 | 0.3 |

- 별 조각 습득 시 연료 +5 충전
- 은신(Q) 시 적에게 감지되지 않음
- 적 감지 범위 = 광원 범위 × 1.5

### 별 조각 등급

| 등급 | 표시 | 경험치 | 획득 방법 |
|------|------|--------|-----------|
| RAW | ★ | 10 | 필드 습득, 적 처치, 채굴 |
| MERGED | ✦ | 120 | RAW 10개 합성 |
| SUPER_MERGED | ✧ | 1,500 | MERGED 10개 합성 |

### 제작 레시피

| 재료 | 결과 | 공격력 | 내구도 |
|------|------|--------|--------|
| RAW × 5 | 기본 별 지팡이 | 8 | 20 |
| 기본 지팡이 × 5 | 정제 별 지팡이 | 20 | 15 |
| 정제 지팡이 × 5 | 빛나는 별 지팡이 | 50 | 10 |

### 채굴

- 광맥에 48px 이내 접근 후 `Z`키로 채굴 (3~7초)
- 기본 산출량: 2~5개 RAW 조각
- NPC와 함께 채굴 시 인원당 +1개 보너스

### 꽃집

맵에 고정 배치된 꽃집에서 합성한 별 조각으로 꽃을 구매할 수 있습니다.

| 꽃 | 가격 | 구매 제한 |
|----|------|-----------|
| 꽃 (분홍) | ✦합성 x1 | 무제한 |
| 금빛 꽃 | ✧초합성 x1 | 무제한 |
| 특별한 꽃 | ✧초합성 x 난이도 꼭짓점 수 | **1회 한정** |

- 구매한 꽃은 맵 위에 장식으로 배치됩니다
- 엔딩 화면에서 피운 꽃 수가 업적으로 표시됩니다
- **특별한 꽃**을 구매하면 진엔딩이 해금됩니다

### 플레이어 주변 밝기

- 망토를 벗은 상태에서는 난이도에 관계없이 플레이어 주변이 보름달 수준으로 밝게 보입니다
- 어두운 난이도(그믐달, 삭)에서도 주변 적/나무/별을 식별할 수 있습니다
- 망토를 입으면 이 밝기가 사라져 적의 감지가 해제됩니다

### 리스폰 시스템

- 별 조각, 광맥, 망치동물은 수가 최대치의 30% 이하로 줄어들면 자동 리스폰됩니다
- 한 번에 소량씩 생성되며, 최대 수를 초과하지 않습니다
- 적은 플레이어에게서 400px 이상 떨어진 곳에 리스폰됩니다

### 이중 점수 시스템

| 점수 | 획득 방법 | 효과 |
|------|-----------|------|
| **빛 점수** | NPC 협력 채굴, 협동 행동 | 망치 변이 방지 |
| **망치 점수** | 적/NPC 공격 | 누적 시 망치동물로 변이 |

### 레벨업

## 등장 개체

### 망치동물 (적)

| 종류 | HP | 공격력 | 속도 | 감지 범위 | 공격 범위 |
|------|----|----|------|-----------|-----------|
| 망치새 | 20 | 5 | 120 | 200px | 25px |
| 망치늑대 | 40 | 10 | 100 | 180px | 30px |
| 망치곰 | 80 | 20 | 60 | 150px | 40px |
| 망치호랑이 | 60 | 25 | 130 | 220px | 35px |
| 망치코끼리 | 150 | 35 | 40 | 120px | 50px |

처치 시 1~3개 RAW 조각 드롭. 난이도 배율이 HP와 공격력에 적용됩니다.

### NPC (4명 고정)

| 성향 | 수 | 초기 신뢰도 | 특징 |
|------|----|-------------|------|
| 우호적 | 1 | 높음 | 협력 채굴 적극 참여 |
| 중립 | 2 | 보통 | 상황에 따라 협력/배신 |
| 적대적 | 1 | 낮음 | 배신 가능성 높음 |

- 신뢰도 > -10이면 협력 채굴 가능 (+5 신뢰도)
- NPC 공격 시 -30 신뢰도, +3 망치점수
